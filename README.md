# Particle Planet

An interactive particle-planet sandbox with optional hand tracking, mouse/touch controls, synthesized deep-space music, dynamic themes, and cosmic events.

## Controls

- Drag: orbit the planet
- Wheel or pinch: zoom
- Click: gravity-wave note
- Hold: create a black hole
- Double-click: supernova
- Space: warp jump
- 1-4: switch celestial themes
- R: random cosmic event

Hand tracking is optional and only requests camera access after the user clicks the gesture button.
